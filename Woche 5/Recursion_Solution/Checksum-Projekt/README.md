# Checksum

Implementieren Sie die Methode `Calculations.checksum(int x)`. Der Parameter
`x` ist nicht negativ. Die Methode soll die Quersumme von `x` zurueckgeben.
Verwenden Sie fuer die Implementierung keine Schleife.

Das Programm kann mit `./gradlew run` (Windows: `gradlew.bat run`) gestartet
werden. Die Tests laufen mit `./gradlew test` (Windows: `gradlew.bat test`).
